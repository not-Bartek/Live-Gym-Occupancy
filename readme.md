# Gym Occupancy

## Wizja
Aplikacja ma w czasie rzeczywistym wyświetlać liczbę ludzi obecnych na siłowni. Pomogłoby to chętnym wybierać godziny, w których ludzi jest mniej, a także dałoby siłowniom dane o liczbie ćwiczących.
